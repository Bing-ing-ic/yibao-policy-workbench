# 医保政策实时监测工作台 · 只读分享版

本仓库是「医保政策实时监测工作台」的**只读分享版**发布源，通过 GitHub Pages 对外提供访问。页面为一个单页看板，访客可在其中浏览三级政策动态、查看政策摘要与解读要点，并检索医保政策知识库。

- 站点用途：供**澄江市凤麓街道社区卫生服务中心**医保经办、收费、院办人员**内部工作参考**，帮助快速确认「有没有新政策、对本中心收费/结算/基金监管有何影响、是否需上报澄江市医保局」。
- 访客定位：内部工作人员；站点虽公开可访问，但内容定位为内部工作参考，不面向公众提供政策咨询或办理服务。
- 核心动作：在 30 秒内定位并读完一条与本中心相关的政策变动条目，**查到并确认**，不设注册、留资或写入。

## 数据来源与口径

- 数据来自**公开医保政策文件**与**本地整理索引**，由自动化脚本按固定映射规则生成静态 JSON，不含个人信息、不含任何访问凭证。
- 政策按行政层级分为三级，以**玉溪市为关注重点（执行层）**、**云南省为省级依据（参照层）**、**国家为方向指引（基线层）**。三级条目数量与占比以页面顶部统计为准，关注重点指工作参考的优先级，不代表条目数量排序。
- 三份数据文件均为构建时生成的**静态快照**：
  - `data/policies.json`：政策监测台账；
  - `data/state.json`：工作台状态（数据截止时间、三级统计、构建溯源）；
  - `data/kb.json`：医保政策知识库条目。
- 数据字段中的「原文链接」仅在原文地址为 `http(s)://` 时写入，指向发文机关或官方渠道；解读类字段在无可信来源时留空并显示「未评估」，不推断、不臆造。

## 同步机制与时效性

- 数据由本地自动化任务**每日 08:30（北京时间）**更新索引并重新生成上述三份 JSON，随后同步到本仓库，页面在访客下次刷新时读取到新数据。
- 本站点为**准实时快照，不是实时推送**。页面顶部展示的「数据截止时间（`freshness.lastCheckedAt`）」即本份数据的截止时刻；在此之前发生的变动可能尚未反映。
- 数据新鲜度由独立的检查流程看护：若截止时间距检查时刻超过 48 小时，会自动开一个「数据新鲜度告警」Issue 提醒维护人核对同步链路。

## 只读说明

- 本站为只读发布物：**不可写入、不可修改数据**。页面中的写类操作被拦截，调用写入接口会被拒绝并提示「只读部署版不可写入」。
- 完整的**可写工作台**保留在 WorkBuddy 平台内部使用，本站点不替代它，也不收集任何表单或用户信息。
